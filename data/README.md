# Dataset Documentation

This directory manages all input datasets and feature-engineered artifacts for the **Store Sales & Demand Forecasting** project.

> [!NOTE]
> Large CSV files (>100MB) are excluded from Git version control via `.gitignore` to comply with GitHub file size constraints. Follow the instructions below to download and set up the raw data.

---

## 1. Data Source
The dataset is from the Kaggle competition:
**[Store Sales - Time Series Forecasting](https://www.kaggle.com/competitions/store-sales-time-series-forecasting/data)**
*(Corporación Favorita Grocery Sales in Ecuador)*

---

## 2. Directory Structure

```text
data/
├── raw/                               # Original datasets downloaded from Kaggle
│   ├── train.csv                      # Historical sales (store_nbr, family, sales, onpromotion)
│   ├── test.csv                       # Test horizon dates for prediction
│   ├── stores.csv                     # Store metadata (city, state, type, cluster)
│   ├── oil.csv                        # Daily crude oil price (WTI)
│   ├── holidays_events.csv            # National, regional, and local holiday calendar
│   ├── transactions.csv               # Daily transaction counts per store
│   └── sample_submission.csv          # Submission format template
│
└── processed/                         # Generated by notebooks 01, 02, and 03
    ├── train_processed.csv            # Cleaned training data (Notebook 01)
    ├── train_processed2.csv           # Type-validated data (Notebook 02)
    ├── train_features.csv             # Full feature matrix with lags, calendar & external features (Notebook 03)
    └── test_features.csv              # Test feature matrix ready for inference (Notebook 03)
```

---

## 3. How to Obtain the Raw Data

### Option A: Using the Kaggle CLI (Recommended)
Make sure you have the [Kaggle API](https://github.com/Kaggle/kaggle-api) installed and configured:

```bash
# 1. Download the competition archive
kaggle competitions download -c store-sales-time-series-forecasting

# 2. Extract into data/raw/
unzip store-sales-time-series-forecasting.zip -d data/raw/
```

### Option B: Manual Download
1. Navigate to [Kaggle Store Sales Data](https://www.kaggle.com/competitions/store-sales-time-series-forecasting/data).
2. Click **Download All**.
3. Extract all CSV files into the `data/raw/` directory.

---

## 4. Reproducing Processed Datasets
Run the notebooks in sequence to regenerate the processed datasets:
1. `notebooks/01_data_exploration.ipynb` -> Generates `data/processed/train_processed.csv`
2. `notebooks/02_data_preprocessing.ipynb` -> Generates `data/processed/train_processed2.csv`
3. `notebooks/03_feature_Engineering.ipynb` -> Generates `data/processed/train_features.csv` and `data/processed/test_features.csv`
